# 3D files

Physical, 3D-printable companion pieces for the Gapplings deck — one figure
per perspective, to hold or place alongside its card.

⚠️ **The figure shape is not yet finalized.** Gapplings was renamed away from
"Meeple" specifically because Carcassonne's publisher holds an EU trademark
on the classic peg-person word *and* shape. Whatever gets modeled here must
be a genuinely distinct shape, not a peg-person redraw — and should be
reviewed by a trademark attorney before anything using it is sold. See the
project README's "Branding note" for the full context.

## Expected files

One file per perspective, named to match the card it accompanies:

- `vision.stl`
- `hearing.stl`
- `motor.stl`
- `cognitive.stl`
- `memory.stl`
- `attention.stl`
- `language.stl`
- `pace.stl`

`.stl` is the required print-ready mesh. Optionally add a `.3mf` (with
material/color info) or a `.step`/`.f3d` source file alongside each `.stl`
if you want the parametric/editable source kept in the repo too.
