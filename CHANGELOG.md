# Changelog

All notable changes to this project are documented here, along with *why*
each change was made — not just what changed.

## [0.2.1] - 2026-09-12

### Added
- This changelog, to track version history and the reasoning behind changes
  going forward.

## [0.2.0] - 2026-09-12

### Changed
- Renamed the product (and repo) to **"Gapplings"**, dropping the "A11y"
  prefix along with the earlier name — it existed only to disambiguate from
  that earlier name, which is no longer relevant once this name itself is
  distinct.

### Why
The earlier name and its associated peg-person shape are protected by a
third party's registered EU trademark, actively enforced against other
projects using it. Since this kit is planned for commercial sale from
Norway into EU/EEA markets, continuing to use that branding was a real
infringement risk. "Gapplings" ties into the existing Gap Coin / "Memento
Intervalli" concept instead, and is fully distinct.

### Added
- `3d/README.md` — placeholder structure (manifest + print-setting fields,
  no geometry yet) for upcoming 3D-printable companion figures, one per
  perspective.

### Known issues / not yet resolved
- The icon artwork still visually depicts the classic peg-person silhouette
  and has **not** been redrawn. Renaming the text removes the *word-mark*
  risk but not the *shape/trade-dress* risk. **This kit is not cleared for
  commercial sale** until new artwork/a physical figure shape replaces the
  peg silhouette, and a trademark attorney has reviewed the final name and
  shape.

## [0.1.0] - 2026-09-12

### Added
- Initial print-and-play perspective card deck: Vision, Hearing, Motor,
  Cognitive, Memory, Attention, Language, Pace, plus intro/principle/action/
  blank/back cards and a fold-and-glue tuck box template.

### Why
Split out of a combined multi-tool HTML prototype into its own standalone
repo under the A11y Intuition Lab GitHub org, alongside sibling repos for
the Fidget Tokens and Gap Coin.
